Tick each item and note the date, browser and result. Sample files are in `docs/phase2-test-samples/`; the full walkthrough is `docs/PHASE2_TESTING_GUIDE.md`.

| Check | Result | Date |
|---|---|---|

| Windows, Chrome: same as Edge | | |
| Safari (Mac): Add to Dock, open, add a note, back up and restore | | |
| Second device on the same network: confirm the app is NOT reachable by default (loopback only) | | |
| Real project for one week (non-sensitive): import, approve, record a decision, build and export a handover | | |
| Backup, close the browser, restore on a fresh profile: all cards back | | |
| "What can this app do here?" (Harvester, bottom): every Yes/No matches what you expect on this machine | | |

Exit criteria for the pilot (STR-02): backup and restore works, handover has source references, nothing invented, readable when shared, degraded modes (offline, no AI) work.
