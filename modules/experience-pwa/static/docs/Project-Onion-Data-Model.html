◉ IDs — immutable anchor vs mutable finance tag

  • Project_ReferenceID — project_card · PRIMARY_UNIQUE — immutable system anchor, auto-generated once per project card: [Prefix]-[OppID]-[DDMMYY][Seconds] (e.g. Apollo-O-008891-22092645). Never random hex. One card holds one-to-many IDs.
  • ProjectID / project_ids[] — project_card · PRIMARY_UNIQUE — mutable finance tag array (e.g. 99974052, 0000606071). Matching must strip leading zeros before compare (0000606071 = 606071).
  • Card ID — raid_agg · primary — hash(sources + description_norm). Multiple RAID rows → multiple cards.
  • Opportunity / GDP / Connected — example Opp O-008891, GDP 8399 / 7189, Salesforce 006Uj00000QOBkvIAH. GDP dates are mutable via gdp_dash → project_card [DATE_RANGE].

⚙ Typed-filter enum — the only allowed matching

From reusable_config_pattern.filter_keywords_typed. No free-text parsing anywhere.

  • EXACT — Account Name, Project ID, Opportunity ID, GDP ID, Thread normalized
  • CONTAINS — Project name tokens, SoW/PO/Contract numbers, RAID Type detection
  • DOMAIN — Client email domains, attendee domains in VTT
  • DATE_RANGE — Anchor start/end, GDP mutable dates, last_scanned_date delta
  • TOKEN_OVERLAP — Project name split tokens vs email/Teams/chatter
  • URL_CONTAINS — GDP /project-details/{id}, SharePoint URLs, Connected record ID
