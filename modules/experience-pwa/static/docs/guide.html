◉ Phase 1 — Harvest

Paste anything — email, Teams ping, RAID row. Codes (FW-REQ-4471, PO-88921) + topic words decide the suggestion.

🟡 Smart Append · 100 = match on an existing card.
🟢 New Card = no match, create shared.
Try: UAT deploy FAILED pending FW-REQ-4471. Opp O-008891. → yellow Append.

⚙ Matching

Business codes (FW / PO / SoW / AP / MS / R) on a card → score 100. Opportunity IDs alone never attach. Else 2+ shared words or title match → private draft; otherwise new shared card.

◉ Phase 2 — Who sees it?

Client → project → privacy + persona. Shared = team. My Notes = only yours. Both = both.

Try: switch persona → other private cards disappear.

⚙ Visibility

Client picker, project link, then privacy + persona. Wrong client, unlinked project, or another author's private = hidden.

◉ Phase 3 — Drafts in a card

White = shared. Amber = your draft — only you see it.

Try: approve → amber appears → switch persona → gone → switch back → returns.

⚙ Drafts

Shared shows for all; private/pending shows for the author only.

◉ Phase 4 — Approve, then Sync

🔴 Approve drafts + redacted share → 🔵 Sync Now → 🟢 synced.

Try: new card → blue Sync → synced. Appended card → red first, blue hidden until approved.

⚙ Order

Drafts → privacy review → sync. Sync appears only when approved + stored locally.

◉ Map + IDs

Client → project anchor (one key → many IDs, URLs, channels, contacts, SoW/PO) → sources → grouped cards. One stable key per project; finance IDs ignore leading zeros.

⚙ Codes

Example IDs: O-008891 · PO-88921 · SoW-2024-001 · FW-REQ-4471. Filters: exact, contains, domain, date-range, URL, token.

◉ Privacy screen

Screening keeps business codes, removes personal chatter.

Try: Jane likes coffee + PO-88921 approved → coffee gone, PO kept.

⚙ Flags

Clean or Redacted_Review. Fixed fields: id, project, type, title, source, time, text, privacy, sync.

◉ 60-second checklist

1) FW-REQ → yellow append → approve → amber.
2) Switch persona → amber gone.
3) Back → approve → Sync → synced.
4) Unrelated text → New Card → Sync.

⚙ Quick rules

Codes → 100 append · O-only → new card · 2+ words → private draft · offline → stored locally · red blocks blue.

How it fits together

Harvest → check visibility → review drafts → approve + sync. Left = what to do, right = how the app enforces it.
