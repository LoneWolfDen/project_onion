# Archive

Retired code and superseded documents. Nothing here is built, run or tested by CI. Files were moved with `git mv`, so history is intact.

- `modules/`: Python services and spec folders from the hackathon (anchor, cards store, GDP adapter, admin, numbered module specs). The pilot runs without them.
- `docs/`: earlier backlogs, version notes, registration field specs, implementation audits.
- `root/`: earlier root documents (`STATE.md`, `GLOBAL_BRAIN.md`, audit logs).

Some archived pages and the in-app relationship model still mention these services as historical context.
